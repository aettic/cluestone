# ADR-0002 | Should Cluestone use AI for deck and card performance analysis?

**Status:** Accepted
**Date:** 2026-08-26

## Context

As we are moving into a world that features more and more use of AI and large language models to understand, analyze, and improve things, the question has come up multiple times: Should Cluestone use AI for deck and card performance analysis?

## Decision

At least at launch, Cluestone will not use AI technology in its features. Instead, Cluestone will rely on more basic analysis of data to provide factual insights rather than subjective observations and suggestions. Players will be able to see deck performance over time, how a deck's performance is affected by revisions, and even how individual cards have performed in a given game or across multiple games. These insights can help players make smarter decisions about how to improve their decks, without relying on an AI to come up with the decisions for them.

## Alternatives Considered

### [AI-driven analysis features]

Using an AI to analyze deck performance over time.

## Consequences

+ Better for the environment
+ Simpler implementation
