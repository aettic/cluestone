# User Stories
## Deck lists

### Player

As a player, I want to store my current deck list, so I can quickly reference which cards are in it.

As a player, I want the ability to make quick edits to my deck list (by swapping cards in and out) so that I can keep it current.

As a player, I want to be able to import my deck list from an existing service or as a text-based list, so that I can quickly get my deck brought into Cluestone for use at the table.

As a player, I want the ability to export my current deck list in plain-text, so that I can use it in other places or for other purposes.

As a player, I want options for changing how I view my cards, to best fit the style that works for me.

As a player, I want to see stats for my deck including mana curve, power / bracket level, color breakdown by cost and production, quantities of card types.

As a player, I want to be able to sort and filter cards in my deck list view, so that I can narrow in on specific types of cards for analysis-sake.

As a player, I want a quick way to be able to track performance at a deck level (wins and losses) after a game, so that I can capture that information without stressing about it.

As a player, I want to see how my deck's performance changes from version to version, so that I can identify whether the changes I've made are positive or negative.

As a player, I want to be able to track whether cards are performing well or poorly in a deck, so I can more quickly identify appropriate potential cuts.

As a player, I want the ability to mark cards with specific tags so I can see categorized cards at a glance (such as cards I own, cards I am going to get, cards I have proxied, etc.)

## Backlog / Feature Requests

### Player

As a player, I want to see how my deck compares to other players' decks of the same commander, so that I can see what works better.
