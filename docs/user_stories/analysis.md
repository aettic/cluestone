# User Stories

## Analysis

### Player

As a player, I want to see an overview of a deck's performance, including games played, wins, losses, and win rate, so that I can quickly understand its results.

As a player, I want drawn and abandoned games to be excluded from performance statistics, so that games without a winner do not distort my deck's results.

As a player, I want to see how a deck's performance changes over time, so that I can identify improving or declining trends.

As a player, I want to compare the performance of different revisions of the same deck, so that I can understand whether my deck changes were associated with better or worse results.

As a player, I want to see which cards were added and removed between deck revisions, so that I have context when comparing their performance.

As a player, I want to filter analysis by a date range, so that I can focus on a relevant period of play.

As a player, I want to filter a deck's results by opponent, opposing deck, or commander, so that I can explore which matchups have been more or less successful.

As a player, I want to see a deck's results grouped by the number of players in each game, so that games with different table sizes can be understood separately.

As a player, I want to compare results from games in which I started with games in which another player started, so that I can understand whether turn order appears to affect my results.

As a player, I want to see the typical number of turns or rounds in my deck's completed games, so that I can better understand its pace and when it tends to win or lose.

As a player, I want to review the games included in a statistic, so that I can understand where the result came from and identify unusual games.

As a player, I want Cluestone to show the sample size behind every statistic, so that I do not give too much weight to results based on only a few games.

As a player, I want analysis to clearly distinguish recorded facts from estimates or suggestions, so that I understand how much confidence to place in an insight.

As a player, I want analysis to remain available offline for games and deck information stored on my device, so that I can review my decks without an internet connection.

As a player, I want to see an informative empty state when there is not yet enough data for an analysis, so that I know what information must be recorded before the feature becomes useful.

## Backlog / Feature Requests

### Player

As a player, I want to record brief post-game observations about cards that performed particularly well or poorly, so that card-level analysis is based on my actual experience.

As a player, I want to see card observations across games and deck revisions, so that I can identify repeated strengths or problems rather than relying on one memorable game.

As a player, I want to see whether adding or removing a card coincided with a change in deck performance, so that I can investigate the effect of deck-building decisions without treating correlation as proof of causation.

As a player, I want to compare my deck with other decks using the same commander, so that I can discover meaningful differences and possible improvements.

As a player, I want Cluestone to suggest questions or areas worth investigating, so that the analysis helps guide my judgment without prescribing how I should build or play my deck.

As a player, I want to export an analysis summary, so that I can preserve or share what I have learned outside Cluestone.
