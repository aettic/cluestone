# Cluestone
An application to track MTG Commander games, deck progression, and stats

## Features
- Tracking info about the game while playing with friends
	- Background color or card art image
	- Naming
	- Store users and their decks
	- Guest users (player name, minimum include a deck name)
- Storing deck information
- Deck list change tracking and notes
- Wins / Losses
- Data to track how the deck performs before and after deck list changes
- Account for storing decks online
- Integrate with Scryfall for images and metadata
- Card search
- Notes on individual cards in a deck
- Login / OAuth
